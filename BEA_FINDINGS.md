# BEA Investigation Findings

## Date
2026-06-07

## 1. interstate.csv vs trade.csv

Status: Investigated

Findings:
- interstate.csv is NOT a replacement for trade.csv.
- trade.csv remains the core trade flow table.
- interstate.csv is a US domestic state-to-state trade enhancement generated by BEA processing.
- trade.csv contains:
  trade_id, year, region1, region2, industry1, industry2, amount
- interstate.csv contains:
  trade_id, year, region1, region2, industry1, industry2, amount,
  commodity_code, industry_code, economic_multiplier
- interstate.csv is consumed by:
  - state export competitiveness
  - state import dependency
  - interstate_factor generation

Recommendation:
- Keep interstate.csv as a parallel BEA-enhanced table.
- Do not replace trade.csv.

Evidence:
- tradeflow/bea/main.py
- tradeflow/bea/README.md
- tradeflow/bea/main_trade_analyzer.py
