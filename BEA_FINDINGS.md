### EPA Reduction Findings

EPA reduces the published import factor outputs in several ways:

1. Factor reduction:
   - EPA keeps only 5 air-emission flowables:
     - Carbon dioxide
     - Methane
     - Nitrous oxide
     - Sulfur hexafluoride
     - HFCs and PFCs, unspecified
   - These correspond to greenhouse-gas emissions rather than the full Exiobase stressor list.

2. Industry reduction:
   - Detail outputs contain 298 sectors.
   - Summary outputs contain 44 sectors.

3. Region reduction:
   - Regional outputs use 7 regions.
   - They do not publish every individual Exiobase country in the final regional factor files.

4. File-size reduction:
   - EPA's largest published output is only 5.6 MB.
   - Largest factor output is 1.2 MB.
   - This is much smaller than ModelEarth's current generated BEA domestic files, especially:
     - interstate_factor.csv: 628 MB
     - interstate.csv: 325 MB
     - export_competitiveness_state.csv: 192 MB
     - import_dependency_state.csv: 191 MB

### Interpretation

EPA achieves small publishable CSVs by reducing across multiple dimensions:
- only selected greenhouse-gas factors
- grouped regions
- detail/summary sector schemas
- pre-aggregated import factor outputs

This suggests ModelEarth should not publish raw interstate-factor rows directly for GitHub-sized output. Instead, we likely need a reduced/published 
output layer similar to EPA's approach.

### EPA Flow Mapping Strategy

EPA does not use a top-N stressor strategy for the published 2019 Exiobase import factor outputs.

For EXIOBASE, the reduction is configured in `mrio_config.yml` using prefix-style flow mappings:

- `CO2` → Carbon dioxide
- `CH4` → Methane
- `HFC` → HFCs and PFCs, unspecified
- `N2O` → Nitrous oxide
- `PFC` → HFCs and PFCs, unspecified
- `SF6` → Sulfur hexafluoride

For GLORIA, EPA uses `gloria_mapping.csv`, which maps:
- 390 source flows
- into 33 target FEDEFL-style flows

The 2019 Exiobase output files inspected contain only 5 final Flowables, matching the EXIOBASE greenhouse-gas mapping strategy.

Interpretation:
EPA reduces the raw MRIO factor space by mapping source flows into a small reporting vocabulary, rather than retaining all factors or selecting top-N factors by 
coefficient magnitude.

Implication for ModelEarth:
To reproduce EPA-style reduced outputs, ModelEarth should add a reduced publication layer that maps raw Exiobase factor/stressor names into a small set of 
greenhouse-gas output categories before writing GitHub-sized CSVs.

industries, regions, or other reporting dimensions.

### EPA Aggregation Strategy

EPA's final output reduction happens in `calculate_and_store_emission_factors()`.

Reduction logic:
- Calculates `FlowAmount = EF * import contribution`.
- Drops rows with missing import quantity.
- Aggregates regional outputs by:
  - Region
  - Sector
  - flow metadata (`Flow`, `Compartment`, `Unit`, `Year`, `PriceType`, `Flowable`, `Context`, `FlowUUID`, `ReferenceCurrency`)
- Aggregates national outputs by:
  - Sector
  - the same flow metadata

Key conclusion:
EPA does not publish row-level trade/interstate-factor records. It publishes pre-aggregated reporting tables.

Implication for ModelEarth:
To match EPA-style reduced output size, ModelEarth should create a reduced publication layer that aggregates by reporting dimensions such as region/state, sector/industry, 
and reduced flowable/impact category, instead of publishing raw `interstate_factor.csv` rows.
